# PAMC204とNewport Model8742のコマンド互換性

## コマンド対比表

> **免責事項:** 本ドキュメントはPAMC204とNewport Model8742のコマンド互換性に関する参考資料です。コマンドは互換性を考慮して設計されていますが、ハードウェア実装の違い、ファームウェアの動作、デバイス固有の機能などにより、**100%の互換性を保証することはできません**。実際の運用環境では、すべてのコマンドを十分にテストしてからご使用ください。

### 基本概念の対応関係

- **周波数 (PAMC204) [pulses/sec] = Velocity (Model8742) [steps/sec]**
- **パルス数 (PAMC204) [pulses] = ステップ数 (Model8742) [steps]**

### 主要コマンド対比

| 機能 | PAMC204 | Newport Model8742 | 備考 |
|------|---------|-------------------|------|
| **1. ファームウェアバージョン確認** | `ExxINF` | `VE?` または `*IDN?` | PAMC204: ファームウェアバージョンとボーレート表示<br>Model8742: 2つのコマンドあり |
| **2. アドレス確認** | `Exx` | `SA?` | PAMC204: xx=01-32、応答=`ExxOK`<br>Model8742: 1-31 |
| **3. アドレス設定** | `SETADDRxx` | `SA nn` | PAMC204: 単一接続時のみ使用可能<br>両方ともRS-485ネットワーク用 |
| **4. 出力電圧調整** | `ExxDACnnnn` | - | PAMC204固有機能（70-150V）<br>nnnn: 1900-4095（9段階） |
| **5. 正回転駆動** | `ExxNRnnnnyyyyz`<br>`ExxNRnnnnXyyyyyyz` | `xxPA nn`<br>`xxPR nn`<br>`xxMV+` | PAMC204: 周波数(1-1500Hz)+パルス数(0-9999 or 0-999999)指定<br>yyyy=0000で連続駆動<br>Model8742: 絶対位置/相対移動/連続 |
| **6. 逆回転駆動** | `ExxRRnnnnyyyyz`<br>`ExxRRnnnnXyyyyyyz` | `xxPA nn`<br>`xxPR nn`<br>`xxMV-` | 同上（逆方向） |
| **7. 停止** | `ExxS` | `xxST`<br>`AB` | PAMC204: 連続駆動停止、応答=`ExxFINnnnn`（駆動パルス数表示）<br>Model8742: ST=減速停止、AB=即停止 |
| **8. モーション停止** | `ExxAB` | `AB` | PAMC204: 全CH即停止<br>Model8742: 全軸即停止 |
| **9. 速度設定** | `ExxmVAnnnn` | `xxVA nn` | PAMC204: 1-1500 steps/sec、m=1-4（CH指定）<br>Model8742: 1-2000 steps/sec |
| **10. 速度問い合わせ** | `ExxmVA?` | `xxVA?` | PAMC204: m=1-4（CH指定） |
| **11. ホームポジション設定** | `ExxmDHnnnn` | `xxDH nn` | PAMC204: m=1-4（CH指定）、nnnn=-2147483648~+2147483647<br>Model8742: 絶対位置設定 |
| **12. ホームポジション問い合わせ** | `ExxmDH?` | `xxDH?` | PAMC204: m=1-4（CH指定） |
| **13. 絶対位置移動** | `ExxmPAnnnn` | `xxPA nn` | PAMC204: m=1-4（CH指定）、nnnn=-2147483648~+2147483647 |
| **14. 絶対位置問い合わせ** | `ExxmPA?` | `xxPA?` | PAMC204: m=1-4（CH指定）、駆動中は目標位置、停止中は実位置を返す |
| **15. 相対位置移動** | `ExxmPRnnnn` | `xxPR nn` | PAMC204: m=1-4（CH指定）、nnnn=-2147483648~+2147483647 |
| **16. 相対位置問い合わせ** | `ExxmPR?` | `xxPR?` | PAMC204: m=1-4（CH指定）、駆動中は目標位置、停止中は実位置を返す |
| **17. 実位置問い合わせ** | `ExxmTP?` | `xxTP?` | PAMC204: m=1-4（CH指定）、現在の実位置を返す |
| **18. 動作状態確認** | `ExxmMD?` | `xxMD?` | PAMC204: m=1-4（CH指定）、0=駆動中、1=停止<br>Model8742: 0=動作中、1=停止 |
| **19. 無限移動** | `ExxmMVn` | `xxMV+/-` | PAMC204: m=1-4（CH指定）、n=+/-（方向指定） |
| **20. 移動方向問い合わせ** | `ExxmMV?` | - | PAMC204固有、m=1-4（CH指定）、0=駆動中、1=停止 |
| **21. 動作停止** | `ExxmST` | `xxST` | PAMC204: m=1-4（CH指定）、減速停止<br>Model8742: 減速停止 |
| **加速度設定** | - | `xxAC nn` | Model8742固有: 1-200000 steps/sec² |
| **モータータイプ設定** | - | `xxQM nn` | Model8742固有機能 |

### パラメータ詳細対比

#### PAMC204のコマンドパラメータ

| パラメータ | 範囲 | 説明 |
|-----------|------|------|
| `xx` | 01-32 | ドライバアドレス |
| `m` | 1-4 | チャンネル番号（位置制御コマンド用） |
| `nnnn` | 0001-1500 | 駆動周波数 (Hz) または 速度 (steps/sec) |
| `yyyy` | 0000-9999 | パルス数（0000=連続駆動） |
| `yyyyyy` | 000001-999999 | 拡張パルス数（X付き） |
| `z` | A-D | 駆動軸 (A=CH1, B=CH2, C=CH3, D=CH4) |
| `nnnn` (DAC) | 1900-4095 | 出力電圧設定値 |
| `nnnn` (位置) | -2147483648 ~ +2147483647 | 絶対位置・相対位置 |
| `n` (方向) | +/- | 移動方向（+: 正方向、-: 負方向） |

#### Model8742のコマンドパラメータ

| パラメータ | 範囲 | 説明 |
|-----------|------|------|
| `xx` | 1-4 | 軸番号 |
| `nn` (VA) | 1-2000 | 速度 (steps/sec) |
| `nn` (AC) | 1-200000 | 加速度 (steps/sec²) |
| `nn` (PA/PR) | -2147483648 ~ +2147483647 | 位置（ステップ数） |
| `nn` (QM) | 0-3 | モータータイプ |

| エラー | 説明 |
|--------|------|
| `Error Value Range` | 出力電圧調整中に指定の値が範囲外 |
| `ERROR` | 回転方向指定が間違い/周波数が範囲外/チャンネル指定が範囲外 |
| `ERROR1` | コマンドが認識できない |
| `ERROR4` | パルス数指定が6桁の時に範囲外 |
| `ERROR5` | パルス数指定が4桁の時に範囲外 |

| エラーコード | 説明 |
|-------------|------|
| 0 | エラーなし |

#### 例1: モーター1を1500Hzで1500パルス正回転

**PAMC204:**

```

```

**Model8742:**

```
1VA1500

```

#### 例2: モーター2を連続正回転

**PAMC204:**

```

```


### 主な違いのまとめ

1. **コマンド体系**
   - PAMC204:
     - パルス駆動コマンド: 1コマンドで周波数とパルス数を同時指定（`ExxNR`/`ExxRR`）
     - 位置制御コマンド: Model8742互換の位置制御コマンド対応
   - Model8742: 速度設定と移動コマンドを分離

2. **電圧制御**
   - PAMC204: 出力電圧を70-150Vで調整可能（`ExxDACnnnn`）
   - Model8742: 電圧制御機能なし

3. **位置管理**
   - PAMC204: パルス数ベースの制御と位置ベースの制御の両方に対応
   - Model8742: 絶対位置・相対位置の概念あり、ホームポジション設定可能

4. **ネットワーク**
   - PAMC204: アドレス範囲 01-32
   - Model8742: アドレス範囲 1-31、Ethernet対応

5. **モーター管理**
   - PAMC204: 4軸、同時に1軸のみ駆動
   - Model8742: 4軸、モータータイプ自動検出機能あり

### 移行時の注意点

1. **コマンド体系の選択**
   - パルス駆動コマンド: 1コマンドで周波数とパルス数を同時指定（シンプル）
   - 位置制御コマンド: Model8742互換、位置管理が可能（高機能）

2. **電圧制御**
   - PAMC204固有の`ExxDACnnnn`コマンドで出力電圧調整可能
   - Model8742には電圧制御機能がないため、速度パラメータで調整

3. **位置管理**
   - PAMC204: Model8742と同様の位置フィードバック機能を実装
   - 絶対位置・相対位置・ホームポジション設定が可能

4. **エラーハンドリング**
   - エラーコード体系が異なるため、エラー処理ロジックの見直しが必要
   - PAMC204は文字列ベース、Model8742は数値コードベース

5. **同時駆動制限**
   - PAMC204: 1台あたり同時に1CHのみ駆動可能
   - 別のCHを駆動すると現在駆動中のモーターは自動停止
